# 🎬 Netflix Clone - Containerized Production Setup

A high-fidelity frontend clone of Netflix, optimized and containerized using production-grade DevOps methodologies.

---

## 🛠️ Tech Stack & Tools Used
* **Frontend UI:** HTML5, CSS3, JavaScript (ES6+)
* **Containerization:** Docker Engine
* **Web Server:** Nginx (Alpine-based)
* **CI/CD Automation:** GitHub Actions

---
